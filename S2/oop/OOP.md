***Encapsulation*** grouping data and methods that operate on them in single entity using encapsulation we are hiding the internal state of an object and exposing just limited functionality to interact with the object.
***Abstraction:*** hiding the implementation details and and exposing just the essential features of the object 
***Abstract data types**:* a defined data type that is independent from any specific implementation.
