### Types of Data communication:
- Simplex: only one way communication.
- Half-Duplex: both ways communication but one at a time.
- Full-Duplex: both ways communication at the same time.
### Protocols:
All communication schema will have the following things in common:
- Source and sender
- Destination and receiver
- Channel or media

**Message encoding**:
Message source -> encoder (signal) -> transmitter (medium) -> receiver (signal) -> decoder -> message destination
