The methods for dimensionality reduction include:
1. **Principal Component Analysis (PCA)**: Transforms correlated features into a smaller set of uncorrelated components (principal components) that capture the most variance.
2. **SVP (Statistical Variable Projection)**: A method that identifies and retains the most statistically significant variables while discarding less important ones.
3. **T-SNE (t-Distributed Stochastic Neighbor Embedding)**: A non-linear dimensionality reduction technique that is particularly well-suited for visualizing high-dimensional data in two or three dimensions.
4. **Feature Selection**: Involves selecting a subset of relevant features based on statistical tests, correlation analysis, or model-based methods to improve model performance and reduce overfitting.
