# Security attribute

- **Confidentiality**: keeping your data private and only accessible by authentificated users
- **Authentification**: The origin of information is correctly identified.
- **Integrity**: Only authorized parties can change information
- **Non-repudiation**: neither sender nor reciever can deny that they performed a transaction
- **Access control**: access to information is only controlled and limited to authorized parties.
- **Availability**: Users should access computer assets as needed.













 *Fact: The only secure system is one that is never used*
