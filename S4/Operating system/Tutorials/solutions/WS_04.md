## Given
Total resources:
- A = 6
- B = 28
- C = 24
- D = 24

## Step 1: Calculate Allocated Resources

| Resource | Total Allocated |
|:--------:|:---------------:|
| A        | 2 + 0 + 2 + 0 + 0 = 4 |
| B        | 6 + 0 + 0 + 0 + 12 = 18 |
| C        | 10 + 3 + 0 + 1 + 6 = 20 |
| D        | 8 + 8 + 0 + 4 + 4 = 24 |

## Step 2: Calculate Available Resources

Available = Total - Allocated

| Resource | Available |
|:--------:|:---------:|
| A        | 6 - 4 = 2 |
| B        | 28 - 18 = 10 |
| C        | 24 - 20 = 4 |
| D        | 24 - 24 = 0 |

Thus:


Available = (2, 10, 4, 0)


## Step 3: Calculate Need Matrix (Max - Allocation)

| Process | A | B | C | D |
|:-------:|:-:|:-:|:-:|:-:|
| P1 | 2 | 0 | 0 | 4 |
| P2 | 0 | 17 | 7 | 4 |
| P3 | 0 | 18 | 22 | 0 |
| P4 | 0 | 0 | 1 | 0 |
| P5 | 0 | 0 | 8 | 0 |

### (i) Check Safe State (Banker's Algorithm)

**Available = (2, 10, 4, 0)**

Safe sequence search:
- P4 can execute.  
  New Available = (2, 10, 5, 4)
- P1 can execute.  
  New Available = (4, 16, 15, 12)
- P5 can execute.  
  New Available = (4, 28, 21, 16)
- P2 can execute.  
  New Available = (4, 28, 24, 24)
- P3 can execute.

### Safe Sequence:
\[
P4 \rightarrow P1 \rightarrow P5 \rightarrow P2 \rightarrow P3
\]

**Conclusion**: The system is in a safe state.

### (ii) P3 requests (B=8, C=4)

Request = (0, 8, 4, 0)

- Request ≤ Available (2, 10, 4, 8): Yes

Simulate allocation:
- New Available = (2, 2, 0, 8)

Safe sequence after granting:
- P1 → P4 → P5 → P2 → P3

**Conclusion**: The OS will grant P3's request immediately.

### (iii) P2 requests (B=10, C=4, D=4)

Request = (0, 10, 4, 4)

- Request ≤ Available (2, 10, 4, 8): Yes

Simulate allocation:
- New Available = (2, 0, 0, 4)

Safe sequence attempt:
- P1 can execute.
- P4 can execute.
- P5 can execute.
- P2 can execute.
- P3 cannot execute (insufficient C resources).

**Conclusion**: The OS will not grant P2's request immediately.

### (iv) P5 requests (A=1, C=4)

Request = (1, 0, 4, 0)

- Request ≤ Available (2, 10, 4, 8): Yes

Simulate allocation:
- New Available = (1, 10, 0, 8)

Safe sequence attempt:
- No process can safely execute immediately.

**Conclusion**: The OS will not grant P5's request immediately.
